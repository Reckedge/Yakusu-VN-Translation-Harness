Make a test patch

Translate the first 150 lines of one script, install them, and check them in the game. If text runs out of the box, adjust the size here and apply again. Applying again doesn't re-translate, so it's free.

Translate the whole game

Yakusu translates in batches and saves as it goes, so you can stop at any time and pick up later. When it finishes, it rewrites lines that overflow the text box, then builds and installs the patch.
